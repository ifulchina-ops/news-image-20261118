Eighteen — 18 November 2026 in one front page. A program that writes one image summing up Wednesday 18 November 2026's world news: a broadsheet front page led by Trump's arrival in Manila for Quad talks ahead of his China visit, with Ukraine's second-day strike on the Crimean Bridge, Iran's drone attack on a US radar in Bahrain, Canada–China trade deals ahead of APEC, Britain's sanctions on settlement firms, Cyclone Akvan, and a day-in-brief strip. The artwork is drawn by `build_art.py` (PIL, no network) and copied byte-for-byte by `main.py`, which verifies the PNG size and SHA-256 before finishing.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
